# TDG · Demo de gestión de solicitudes

Propuesta independiente de Agallart Digital. No es una herramienta oficial de TDG.

## Recorrido

- Revisar solicitudes por centro (Alicante / Benidorm), vehículo y servicio.
- Filtrar y buscar; alternar tablero y lista.
- Abrir fichas, añadir notas y cambiar estado y siguiente paso.
- Crear solicitudes de prueba y reiniciar la demo.

Todos los contactos y solicitudes son ficticios. Los servicios y los centros se han tomado de https://tdgclub.es/ (consulta del 6/10/2026). No se presupone una carencia en sus herramientas actuales.

Los cambios viven solo en memoria mientras la página siga abierta. No hay autenticación, base de datos ni conexión a la web, correo, WhatsApp o agenda de TDG. Una cita confirmada aquí es una simulación; no reserva nada. No introducir datos personales reales.

## Uso

GitHub Pages sirve `index.html` desde `main` en la raíz. El archivo es autónomo y también puede abrirse localmente. No requiere instalación ni servicios externos.

## Comprobación

Se comprobó la lógica de filtros combinados, cambios de estado, apertura de fichas, escape de texto, reinicio y rechazo de entradas inválidas. La demo se presenta para revisar el flujo con TDG, antes de acordar alcance, integraciones, precio o plazos.
